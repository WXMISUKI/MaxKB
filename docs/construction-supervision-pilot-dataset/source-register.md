## 入库原则

- 第一批只入库官方来源登记和自写摘要，不直接全量导入所有规范全文。
- 若后续需要全文入库，必须确认来源为官方公开 PDF，并记录下载时间和原始 URL。
- 规范类资料必须带 `basis_version_id` 和 `effective_status`。
- 检索命中规范时，只能作为审查依据引用，不能自动生成正式结论。
